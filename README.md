# Weight Tracker App

An Android mobile application developed using Java, SQLite, and Android Studio. This project demonstrates mobile application development, local database management, user interface design, and software troubleshooting.

## Features

- **User Authentication:** Login and account creation screens.
- **Weight Management:** Add, view, edit, and delete weight records.
- **SQLite Database:** Store and retrieve user and weight information locally.
- **SMS Settings:** Screen for configuring SMS notification permissions.
- **User Interface:** Multiple Android activities with XML-based layouts.

## Technologies Used

- Java
- Android Studio
- SQLite
- Android SDK
- XML
- Gradle

## Application Structure

- `MainActivity.java` — User login and account creation
- `DashboardActivity.java` — Weight tracking and record management
- `DatabaseHelper.java` — SQLite database operations
- `SmsActivity.java` — SMS permission settings

## How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize the project dependencies.
4. Launch an Android emulator or connect an Android device.
5. Build and run the application.
